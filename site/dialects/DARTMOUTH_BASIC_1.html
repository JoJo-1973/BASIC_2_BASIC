    Dartmouth BASIC (1st edition)

    DARTMOUTH_BASIC_1 · John G. Kemeny, Thomas E. Kurtz · 1964 · General Electric GE-225 (other), General Electric GE-235 (other)

    The original BASIC, compiled (compile and go) on the Dartmouth Time-Sharing System and used from Teletype terminals. Only numbers: strings can be printed as labels, not stored.

    Statements

    DATA Numbers for READ, taken in the order of the DATA statements.
    DEF Defines a function FNA to FNZ with one argument.
    DIM Gives lists and tables more elements than the default.
    END Last statement of every program: it must have the highest number.
    FOR...TO...STEP Starts a loop: the variable goes from the first value to the second in steps of 1 or of the STEP value.
    GO TO Jumps to a line.
    GOSUB Calls a subroutine: RETURN goes back to the statement after the GOSUB.
    IF...THEN Jumps to a line if a relation between two formulas is true.
    LET Computes the value of a formula and gives it to a variable.
    NEXT Ends the loop of the FOR with the same variable.
    PRINT Types the values of formulas and labels on a line.
    READ Gives the variables the next numbers of the DATA statements.
    REM Remark: does nothing.
    RETURN Goes back to the statement after the last GOSUB.

    Direct commands

    HELLO Starts a session: the system asks for the user number, the problem name, the system and whether the program is new or old.
    LIST Types the current version of the program.
    RUN Compiles and runs the program.
    SAVE Keeps the program on the disk, under its problem name.
    STOP Stops whatever is going on, even while the Teletype is typing at full speed.

    Data types

    TypeSuffixFamilyRangePrecisionBytesNotes
    Number real [-5.7896e+76, 5.7896e+76] 9 digitsFloating point on the GE-225/235: about 30 bits of mantissa (the manual says up to 9 digits, "the limit of accuracy of the computer"), binary exponent from -256 to 255 (source [6]), so magnitudes from about 4.31809E-78 to 5.78960E76 (the limits printed in the GE manual [3], p. 37). A constant has up to 9 digits, a decimal point and a minus sign, and can be followed by E and a power of ten: 5E1, 2.39E-12 [1] p. 5.

    Variable types

    Variable typeData typeDimensionsNameMaximum lengthSignificant charactersExamplesNotes
    VariableNumber0 one letter, or one letter followed by one digit 2 all A, X, N5, X0, K9 286 names. Only capital letters exist on the Teletype [1] p. 5. The manual does not say what an unassigned variable holds; Kurtz [9] says that variables were first set to zero in the 4th edition.
    ListNumber1 one letter followed by a subscript in parentheses 1 all A(5), B(I+1) A one-dimensional array (vector). Part II of the manual [1] is missing: from the 2nd edition manual [2] and from source [5], whose description of the 1st edition is that a list needs no DIM up to 10 elements, numbered from 1 to 10 (subscript 0 came with the 2nd edition). Kurtz [9] confirms it: without DIM, subscripts 1-10 in each dimension. A letter can be a simple variable and a list at the same time, not a list and a table.
    TableNumber2 one letter followed by two subscripts in parentheses 1 all B(1,1), M(I,J) A two-dimensional array (matrix). Inferred from the 2nd edition manual [2] (Part II of [1] is missing): subscripts from 1 to 10 without DIM, as for the lists.

    Range of line numbers 1-99999 to verify Called instruction numbers; statements are run in the order of their numbers, whatever the order they were typed in [1] p. 4. A line with the number of an existing one replaces it; a number alone deletes the line [1] p. 19.

    Statement separator None to verify
    LET keyword Mandatory to verify Every assignment starts with LET: 10 A=5*5 is not a statement (source [5]).
    Truth values
    Value produced by a true comparison None to verify Relations can only be written in IF...THEN: they produce no value.
    Value produced by a false comparison None to verify Relations can only be written in IF...THEN: they produce no value.
    How a value used as a condition is read Relation only to verify IF needs a relation between two formulas; a formula alone is not a condition.
    Numbers
    Conversion of non-integer values to integers Not stated to verify The manuals do not say what happens to a subscript that is not an integer. INT truncates towards zero (see INT).
    FOR loops
    The body of a FOR loop is always executed at least once No to verify Inferred from the 2nd edition manual [2] pp. 13-14: a loop whose start is already past the final value is not executed at all; the May manual does not say.
    The loop variable can be changed inside the loop Not stated to verify
