    Casio FX-700P BASIC

    CASIO_FX700P · Casio · Casio FX-700P (rom), Casio PB-100 (rom), Tandy Radio Shack TRS-80 PC-4 (rom)

    BASIC of a programmable calculator: numeric variables A-Z, character variables A$-Z$ of up to 7 characters and the exclusive character variable $ of up to 30. The same BASIC runs on the Casio PB-100 (less memory, no F key for the functions) and on its rebrandings TRS-80 PC-4 and Olympia OP-544. Memory addresses in the tables are those of the FX-700P.

    Statements

    = Assignment: gives a variable the value of an expression.
    END Ends the program; it cannot be continued with EXE.
    FOR...TO...STEP Starts a loop: the variable goes from the start value to the end value in steps of the given increment.
    GET Loads variables from tape.
    GOSUB Calls a subroutine; RETURN goes back to the statement after GOSUB.
    GOTO Jumps to a line, or to the start of another program area.
    IF Conditional jump or statement: if the comparison is false, the program goes on with the next line.
    INPUT Stops the program and reads values from the keyboard.
    MODE Chooses the angle unit, or switches the printer on and off.
    NEXT Ends a FOR loop: if the variable plus the increment does not pass the end value, the loop is repeated.
    PRINT Shows numbers and strings on the display.
    PUT Records variables on tape.
    RETURN Ends a subroutine and goes back to the statement after the GOSUB.
    SET Chooses how many significant digits or decimal places the numbers are shown with.
    STOP Stops the program for a while: EXE continues it.
    VAC Clears all variables (sets them to 0).

    Direct commands

    CLEAR Erases the program of the current area, or (CLEAR A) the programs of all areas P0-P9.
    DEFM Turns program steps into memories (variables), or shows how many memories there are.
    LIST Lists the program of the current area, or (LIST A) the programs of all areas and the data in all memories.
    LOAD Loads from tape a program into the current area, or (LOAD A) the programs of all areas recorded with SAVE A.
    RUN Runs the program of the current area.
    SAVE Records on tape the program of the current area, or (SAVE A) the programs of all areas.
    VER Checks that a program or data file has been recorded correctly on tape.

    Data types

    TypeSuffixFamilyRangePrecisionBytesNotes
    Real number real [-1e+100, 1e+100] Absolute values from 1E-99 to 9.999999999E99, and 0; calculations use 12 mantissa digits, the display shows 10 (8 with an exponent). Below 1E-99 the result becomes 0; above the range: error 3. A memory takes the place of 8 program steps. In a program a number is stored as its characters; the exponent is a character of its own: ᴇ (code $1F), or ᴇ- ($1E) for a negative exponent (source [5]).

    Variables area in memory

    Before: nothing. After: nothing. I The memories occupy the end of the RAM, 16 nibbles each, going down: A at $0FF0, B at $0FE0, ..., Z at $0E60, then the expanded memories. The exclusive $ is apart, at $01E0-$021F.

    Error messages

    Shown as ERRn Pa-l: n = error code, a = program area, l = line number (in manual calculation only ERRn). There is no error 8.

    No.MessageDescription
    1 ERR1Memory overflow or system stack overflow: not enough program steps, or a formula too complex for the stack.
    2 ERR2Syntax error: format error in the program, different formats on the two sides of an assignment, etc.
    3 ERR3Mathematical error: a result of 1E100 or more, an argument outside the range of a function, or a result that is indefinite or impossible.
    4 ERR4Undefined line number: the line of a GOTO or GOSUB does not exist.
    5 ERR5Argument error: the argument of a command or function is outside its range.
    6 ERR6Variable error: a memory that has not been expanded, or the same memory used as a numeric and as a character variable at the same time.
    7 ERR7Nesting error: RETURN without GOSUB, NEXT outside a FOR loop, more than 8 subroutine levels or more than 4 FOR loops.
    9 ERR9Option error: no printer or tape recorder connected when PRT mode or a tape command such as SAVE is used.

    Before: nothing. After: $E0 after each program area (assumed from the SAVE A files). I The programs P0-P9 occupy $0220-$0E5F (3136 nibbles = 1568 steps). Memories expanded with DEFM take their room from the end of this area, 8 steps each.

Memory map of the FX-700P: $0000-$00FF buffers, $0100 ANS, $0110 seed of RAN#, $0120 position for MID, $0140-$01BF FOR stack (4 entries), $01C0-$01DF GOSUB stack (8 entries), $01E0-$021F $, $0220-$0E5F programs, $0E60-$0FFF memories Z to A.
