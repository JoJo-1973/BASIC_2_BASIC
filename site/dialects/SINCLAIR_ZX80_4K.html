    Sinclair ZX80 BASIC 4K ROM

    SINCLAIR_ZX80_4K · John Grant (Nine Tiles) · 1980 · Sinclair ZX80 (rom)

    Integer-only BASIC. Statement keywords are entered with a single key.

    Statements

    CLEAR Clears all variables.
    CLS Clears the upper part of the screen.
    DIM Creates an array with subscripts from 0 to n.
    FOR...TO Starts a loop: the counter goes from the start value to the end value in steps of 1.
    GO SUB Calls the subroutine that starts at the given line; RETURN goes back to the next line.
    GO TO Jumps to the given line.
    IF Executes the statement after THEN if the condition is not zero.
    INPUT Reads a value from the keyboard and assigns it to a variable.
    LET Assigns a value to a variable. LET is mandatory.
    NEXT Increments the counter and goes back to the statement after FOR if it has not passed the end value.
    POKE Writes a byte to memory.
    PRINT Writes on the upper part of the screen.
    RANDOMISE Seeds the random number generator.
    REM Comment: it has no effect.
    RETURN Goes back to the line after the last GO SUB executed.
    STOP Stops the program with code 9; CONTINUE resumes from the next line.

    Direct commands

    CONTINUE Resumes execution from the line of the last n/m report; after STOP (9/m) from line m+1.
    LIST Lists the program from a given line, which becomes the current line.
    LOAD Loads from tape system variables, program and variables saved with SAVE.
    NEW Returns the computer to its power-on state: erases program and variables.
    RUN Runs the program: same as CLEAR followed by GO TO n.
    SAVE Saves system variables, program and variables to tape, preceded by 5 seconds of silence.

    Functions

    ABS Absolute value.
    CHR$ Character with the given code.
    CODE Code of the first character of a string.
    PEEK Byte stored at the given address.
    RND Random integer.
    STR$ Number converted to a decimal string (1 to 6 characters, including any minus sign).
    TL$ The string without its first character.
    USR Calls a machine code routine and returns its value.

    Operators

    Arithmetic

    * Multiplication.
    ** Raise to a power.
    + Addition.
    - Change of sign and subtraction.
    / Integer division, truncated towards zero.

    Bitwise

    AND Bitwise conjunction.
    NOT Bitwise negation: NOT n is -n-1.
    OR Bitwise disjunction.

    Relational

    < Less than: -1 if true, 0 if false.
    = Equal: -1 if true, 0 if false.
    > Greater than: -1 if true, 0 if false.

    Grouping

    ( ) Parentheses: the expression inside is evaluated before what surrounds it.

    Error messages

    No.MessageDescription
    0 0/nNo error: command executed, end of program, BREAK pressed, or GO TO a line beyond the end of the program.
    1 1/nNEXT with a variable that is not the counter of an active FOR loop.
    2 2/nUndefined variable (also an array that has not been dimensioned).
    3 3/nArray subscript out of range, or error while computing the subscript.
    4 4/nOut of memory for a new variable, a longer string or the screen.

    6 6/nResult outside the range from -32768 to 32767.
    7 7/nRETURN without a matching GO SUB.
    8 8/nINPUT can only be used in a program.
