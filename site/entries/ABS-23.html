    ABS Function

    Absolute value.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    ABS(n)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): ABS(n)

    Returns: Integer, range [0, 32767] M

    ParameterTypeAllowed valuesDescription
    n numeric expression

    Equivalents in other dialects

    MATH_ABS Absolute value

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameter: n. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameter: n. automatic to verify
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameter: n. automatic to verify

    Examples

    Notes

    ABS(-32768) cannot be typed, because the syntax check rejects the number 32768, but an expression can reach that value: ABS(-32767-1) wrongly gives -32768, without any error (checked on an emulator). This is a bug of the ROM: the returned value stays 0 to 32767 for every other argument.
