    LET Statement

    Computes the value of a formula and gives it to a variable.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964
    In Dartmouth BASIC (4th edition)
    replaced by LET of DARTMOUTH_4ED_layer

    Redefined in a later layer: LET — Strings, and several variables in one LET.

    Syntax

    LET variable = formula

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 7): LET V = F differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    variable M variable
    or list element
    or table element    		 A variable or an element of a list or table.
    formula M formula Any formula.
