    READ Statement

    Gives the variables the next numbers of the DATA statements.

    Layer
    DARTMOUTH_CARD_layer — Card BASIC
    Dialects
    Dartmouth Card BASIC October 1964

    Redefines READ of the previous layer.
    Differences: The numbers come from the data deck after the END card, with no limit.

    Syntax

    READ variable[,variable]...

    In the manual (BASIC (1 October 1964), p. 50-51): READ A, B, C differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    variable M variable or element Variables or elements, separated by commas.

    Equivalents in other dialects

    DATA_READ Read values from the data list

    • Dartmouth BASIC (1st edition) READ
    • Dartmouth BASIC (2nd edition) READ
    • Dartmouth BASIC (3rd edition) READ
    • Dartmouth BASIC (4th edition) READ

    No equivalent in: Casio FX-700P BASIC, Sinclair ZX80 BASIC 4K ROM

    Notes

    The data deck follows the END card: numbers separated by commas, as many per card as wanted, without line numbers or the word DATA; there is no limit on the data [2] pp. 50-51.
