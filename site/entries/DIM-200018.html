    DIM Statement

    Gives lists and tables more elements than the default.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Syntax

    DIM array(n[,m])[,array(n[,m])]...

    In the manual (BASIC (1 October 1964), p. 38): DIM A(17), B(15,20) differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    array I list or table name One letter.
    n I number Largest subscript (of the rows, for a table).
    m I number Largest column subscript of a table.

    Equivalents in other dialects

    VAR_DIM Declare an array partial— Numeric arrays of one or two dimensions

    • Sinclair ZX80 BASIC 4K ROM DIM partial — One dimension only, integers only

    No equivalent in: Casio FX-700P BASIC
