    RND Function

    Random number between 0 and 1.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines RND of the previous layer.
    Differences: No argument.

    Syntax

    RND

    In the manual (BASIC, 4th Edition (January 1968), p. 43-44): RND

    Returns: Number, range [0, 1] M

    Examples

    Notes

    INT(A*RND+B) gives integers from B to A+B-1 [4] p. 44. The same sequence at every run unless RANDOMIZE is used.
