    MAT Statement

    Matrix arithmetic: sum, difference, product, multiple, zero, ones, identity, transpose, inverse.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines MAT of the previous layer.
    Differences: Copy of a matrix (MAT B = A); INV sets DET.

    Sum

    MAT c = a + b

    In the manual (BASIC, 4th Edition (January 1968), p. 53-61): MAT C = A + B

    Errors

    ErrorWhen
    DIMENSION_ERROR The dimensions of the matrices do not agree. to verify
    ILLEGAL_MAT_MULTIPLE The result is also a factor: MAT A = A * B. Form: Product. to verify
    ILLEGAL_MAT_TRANSPOSE MAT A = TRN(A). Form: Transpose. to verify
    ILLEGAL_FORMULA The formula is not written correctly. Parameters: k, m, n. Form: Multiple, Zero matrix, Ones, Identity. automatic to verify
    UNDEFINED_FUNCTION The formula uses an FN function that is never defined. Parameters: k, m, n. Form: Multiple, Zero matrix, Ones, Identity. automatic to verify
    MISMATCHED_STRING A string where a number is wanted. Parameters: k, m, n. Form: Multiple, Zero matrix, Ones, Identity. automatic to verify

    Notes

    Default dimensions: 10 for a list, 10 × 10 for a table; row and column 0 are ignored by MAT but take room. MAT A = A * B and MAT A = TRN(A) are not allowed. A matrix with no inverse does not stop the program: DET is 0 [4] pp. 53-61.
