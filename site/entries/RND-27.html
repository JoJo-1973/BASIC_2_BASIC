    RND Function

    Random integer.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    RND(n)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): RND(n)

    Returns: Integer

    ParameterTypeAllowed valuesDescription
    n numeric expression With n>0 the result goes from 1 to n; with n<0 it goes from 1 to 32767 or from -32768 to n (see the algorithm in the notes); with n=0 it is 1.

    Equivalents in other dialects

    RND_VALUE Random number — Integer from 1 to n

    Keywords

    KeywordTokenAbbreviation
    RND none

    Examples

    Notes

    Algorithm (checked on an emulator against the sequences of RANDOMISE 5 with RND(100) and RND(-10), and of RANDOMISE -5):

    1. Let n be the seed of the pseudo-random generator (a negative seed is read as an unsigned 16-bit number: -5 becomes 65531).
    2. If n = 0, let n = 65536.
    3. Let m = (n*77) MOD 65537.
    4. If m = 65536, let m = 0.
    5. RND(x) gives u*m/65536 + 1 (integer division), where u is x read as an unsigned 16-bit number (x AND 65535: -10 becomes 65526); the result is read as a signed 16-bit integer.
    6. Let n = m and go back to step 2.
