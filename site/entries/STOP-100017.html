    STOP Statement

    Stops the program for a while: EXE continues it.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    STOP

    In the manual (FX-700P Instruction Manual, p. 33): STOP

    Equivalents in other dialects

    • Dartmouth BASIC (4th edition) STOP
