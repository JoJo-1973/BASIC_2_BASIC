    INPUT Statement

    Types a question mark and waits for values typed at the Teletype.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition)
    In Dartmouth BASIC (4th edition)
    replaced by INPUT of DARTMOUTH_4ED_layer

    Redefined in a later layer: INPUT — Strings, and messages for wrong input.

    Syntax

    INPUT variable[,variable]...

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 29-30): INPUT X, Y differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    variable M variable or element Variables or elements, separated by commas; the values are typed the same way.

    Equivalents in other dialects

    IO_INPUT Read values from the keyboard

    • Casio FX-700P BASIC INPUT
    • Dartmouth BASIC (4th edition) INPUT
    • Sinclair ZX80 BASIC 4K ROM INPUT partial — One variable only, no prompt

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964

    Notes

    New in the 3rd edition [5]: for the first time a program can ask for data while it runs. The listings of February 1965 [7] already have it. DTSS-Win (compiler of February 1965) answers a value it cannot read with INPUT DATA NOT IN CORRECT FORMAT. RETYPE IT. and a new question mark (seen in LIB/GUESS).
