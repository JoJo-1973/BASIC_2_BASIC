    TAN Function

    Tangent, in the current angle unit.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    TAN x

    In the manual (FX-700P Instruction Manual, p. 61): TAN x

    Returns: Real number

    ParameterTypeAllowed valuesDescription
    x M numeric expression (-1440, 1440)M In degrees; 8π in radians, 1600 in gradians.
    otherwise error 3 ERR3    		 Constant, variable or numeric expression. Without parentheses only the number or variable that follows is the argument, since functions come first: SIN A+B is (SIN A)+B.
