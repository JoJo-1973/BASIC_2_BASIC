    RESTORE Statement

    Starts the data list again: the next READ takes the first number.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines RESTORE of the previous layer.
    Differences: RESTORE* and RESTORE$ restart only one of the two data lists.

    Both lists

    RESTORE

    In the manual (BASIC, 4th Edition (January 1968), p. 52, 66): RESTORE

    Equivalents in other dialects

    DATA_RESTORE Restart the data list

    • Dartmouth BASIC (3rd edition) RESTORE

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM
