    STOP Direct command

    Stops whatever is going on, even while the Teletype is typing at full speed.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)
    In Dartmouth Card BASIC October 1964
    removed by a higher layer

    Redefined in a later layer: STOP — Inferred: Card BASIC is run from a deck of cards, and the manual does not describe Teletype commands for it.

    Syntax

    STOP

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 18): STOP

    Equivalents in other dialects

    PROG_BREAK Interrupt the running program

    No equivalent in: Casio FX-700P BASIC, Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Notes

    The letters do not show until the typing has stopped, but the command works [1] p. 18.
