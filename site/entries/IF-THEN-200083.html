    IF...THEN Statement

    Jumps to a line if a relation between two formulas is true.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines IF...THEN of the previous layer.
    Differences: Strings can be compared; GO TO can replace THEN.

    Syntax

    IF relation <THEN | GO TO> n

    In the manual (BASIC, 4th Edition (January 1968), p. 35-36): IF ... THEN line differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    relation M relation How a value used as a condition is read: Relation only to verify
    		 Two formulas or two strings joined by a relation.
    n M line number [1, 99999]M
    Range of line numbers: 1-99999 to verify
    missing line: error
    otherwise error UNDEFINED LINE NUMBER    		 Line number: an integer of up to five digits, written as a number (not a formula).

    Errors

    ErrorWhen
    INCORRECT_FORMAT The IF...THEN is not written in its form ([1] p. 19). to verify
    UNDEFINED_NUMBER A jump to a line that does not exist: UNDEFINED LINE NUMBER 50 IN 20 [4] p. 31. Parameter: n. automatic to verify
    ILLEGAL_RELATION The relation is not one of = < <= > >= <>. Parameter: relation. automatic to verify

    Notes

    If the relation is false the program goes on with the next statement. GO TO and IF...THEN may jump to a REM or DATA line, which does nothing [2] p. 45.
