    LOAD Direct command

    Loads from tape system variables, program and variables saved with SAVE.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    LOAD

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): LOAD

    Equivalents in other dialects

    TAPE_LOAD Load the program — No file name: it loads the first program found

    Keywords

    KeywordTokenAbbreviation
    LOAD $FC

    Examples

    Notes

    BREAK during the leader keeps the program in memory; BREAK after the data has started is the same as NEW.
