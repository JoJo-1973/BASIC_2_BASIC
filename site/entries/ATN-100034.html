    ATN Function

    Arc tangent, in the current angle unit.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    ATN x

    In the manual (FX-700P Instruction Manual, p. 61): ATN x

    Returns: Real number

    ParameterTypeAllowed valuesDescription
    x M numeric expression Constant, variable or numeric expression. Without parentheses only the number or variable that follows is the argument, since functions come first: SIN A+B is (SIN A)+B.
