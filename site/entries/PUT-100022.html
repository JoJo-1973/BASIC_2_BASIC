    Casio FX-700P BASIC ›

    PUT Statement

    Records variables on tape.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    PUT [filename] first [, last]

    In the manual (FX-700P Instruction Manual, p. 64): PUT ["filename"] variable differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    filename M string literal Up to 8 letters, digits or symbols, in quotes. Without it, the first file found.
    first M any variable First variable; with $, write it first.
    last M any variable Last variable: all the memories from the first to the last are recorded.

    Equivalents in other dialects

    TAPE_SAVE_DATA Save variables

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    9 OPTION No tape recorder connected. automatic to verify

    Keywords

    KeywordTokenAbbreviation

    Notes

    On tape the file starts with $E0 plus the length of the name; the variables follow, separated by $FF, without their names (source [7]).
