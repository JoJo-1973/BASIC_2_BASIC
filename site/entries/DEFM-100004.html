    DEFM Direct command

    Turns program steps into memories (variables), or shows how many memories there are.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    DEFM [n]
    ParameterTypeAllowed valuesDescription
    n M numeric literal [0, 196]M
    		 Memories to add to the 26 of A-Z: DEFM 30 gives 56. Each memory takes 8 steps. Without n, the number of memories is shown.

    Equivalents in other dialects

    VAR_RESERVE Reserve memory for variables

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    1 MEMORY_OVERFLOW Not enough free program steps for the memories asked for. to verify

    Keywords

    KeywordTokenAbbreviation
    DEFM $C0 S + V (Casio FX-700P), S + V (Casio PB-100), S + V (Tandy Radio Shack TRS-80 PC-4)

    Notes

    The answer is shown as ***VAR:56. The exclusive character variable $ is not counted. According to source [2] DEFM can only be used manually on the PB-100 and FX-700P.

    In a program: not known on the real machine (the manual says the tape commands work only manually). The PokecomGO2 simulator (source [9]) accepts the line and skips the command when it is reached, with no error. Tried with 10 DEFM 5.
