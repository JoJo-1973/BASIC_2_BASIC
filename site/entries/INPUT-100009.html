    Casio FX-700P BASIC ›

    INPUT Statement

    Stops the program and reads values from the keyboard.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    INPUT [message,] variable[,[message,] variable]...

    In the manual (FX-700P Instruction Manual, p. 51): INPUT variable string differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    message M string literal Shown before the question mark: INPUT "A=",A shows A=?.
    variable M numeric variable
    or character variable
    or array element
    or character array element    		 Numeric variable, character variable, $ or array element (numeric or character). For a number an expression or a variable can be typed (14*25, X).

    Equivalents in other dialects

    IO_INPUT Read values from the keyboard

    • Dartmouth BASIC (3rd edition) INPUT
    • Dartmouth BASIC (4th edition) INPUT
    • Sinclair ZX80 BASIC 4K ROM INPUT partial — One variable only, no prompt

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964
