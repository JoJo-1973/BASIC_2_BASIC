    POKE Statement

    Writes a byte to memory.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    POKE address,value

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): POKE n,v differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    address M numeric expression Memory address.
    value M numeric expression Value written modulo 256.

    Equivalents in other dialects

    MEM_POKE Write a byte to memory

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameters: address, value. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameters: address, value. automatic to verify
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameters: address, value. automatic to verify
