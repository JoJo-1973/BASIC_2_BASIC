    OR Operator

    Bitwise disjunction.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    a OR b

    Class: bitwise operators · Precedence: 2 (precedence table)

    Returns: Integer

    ParameterTypeValuesDescription
    a numeric expression
    b numeric expression

    Equivalents in other dialects

    OP_OR Logical disjunction — Bitwise

    Keywords

    KeywordTokenAbbreviation
    OR $E1

    Examples

    Notes

    With truth values (comparisons give -1 if true, 0 if false) it also behaves as a conditional operator: this is a side effect of working bit by bit on signed 16-bit integers, the only numeric type. On the ZX81 and the ZX Spectrum AND, OR and NOT work differently.

    Sources

    • Sinclair ZX80 Operating Manual - A Course in BASIC Programming, Hugo Davenport (1980), p. Appendix II
