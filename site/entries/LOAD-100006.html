    Casio FX-700P BASIC ›

    LOAD Direct command

    Loads from tape a program into the current area, or (LOAD A) the programs of all areas recorded with SAVE A.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Current area

    The display shows PF: and the file name. The old program is erased from the first line number of the loaded one.

    LOAD [filename]

    In the manual (FX-700P Instruction Manual, p. 63): LOAD ["filename"] differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    filename M string literal Up to 8 letters, digits or symbols, in quotes. Without it, the first file found.

    Equivalents in other dialects

    TAPE_LOAD Load the program

    • Dartmouth BASIC (2nd edition) OLD — From the disk of the time-sharing system
    • Dartmouth BASIC (3rd edition) OLD — From the disk of the time-sharing system
    • Dartmouth BASIC (4th edition) OLD — From the disk of the time-sharing system
    • Sinclair ZX80 BASIC 4K ROM LOAD — No file name: it loads the first program found

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth Card BASIC October 1964

    All areas

    Only manually. The display shows AF: and the file name; all the old programs are cleared.

    LOAD A [filename]

    In the manual (FX-700P Instruction Manual, p. 63): LOAD A ["filename"] differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    filename M string literal Up to 8 letters, digits or symbols, in quotes. Without it, the first file found.
