    INT Function

    Largest integer not greater than the argument.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)

    Redefines INT of the previous layer.
    Differences: Floor instead of truncation: INT(-2.35) = -3.

    Syntax

    INT(x)

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 25): INT(X)

    Returns: Number

    ParameterTypeAllowed valuesDescription
    x M formula Any formula.

    Equivalents in other dialects

    MATH_INT Integer part

    No equivalent in: Sinclair ZX80 BASIC 4K ROM
