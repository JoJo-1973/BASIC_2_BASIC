    DEF Statement

    Defines a function FNA to FNZ with one argument.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines DEF of the previous layer.
    Differences: Functions without argument, and functions of several lines ended by FNEND.

    One line

    DEF FNletter[(argument)] = formula

    In the manual (BASIC, 4th Edition (January 1968), p. 46-48): DEF FNA(X) = formula differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    letter M function letter A to Z.
    argument M variable Optional: DEF FNA = 3.1416*R↑2.
    formula M formula Any formula; other variables take their values at the time of the call.

    Equivalents in other dialects

    FN_DEFINE Define a function

    • Dartmouth BASIC (1st edition) DEF
    • Dartmouth BASIC (2nd edition) DEF
    • Dartmouth BASIC (3rd edition) DEF
    • Dartmouth Card BASIC October 1964 DEF

    No equivalent in: Casio FX-700P BASIC, Sinclair ZX80 BASIC 4K ROM

    Several lines

    The lines that follow compute the result and give it to FNx (LET FNA = ...); FNEND ends the definition.

    DEF FNletter[(argument)]

    In the manual (BASIC, 4th Edition (January 1968), p. 46-48): DEF FNA(X) differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    letter M function letter A to Z.
    argument M variable Optional.

    Equivalents in other dialects

    FN_DEFINE Define a function — Several lines, ended by FNEND

    • Dartmouth BASIC (1st edition) DEF
    • Dartmouth BASIC (2nd edition) DEF
    • Dartmouth BASIC (3rd edition) DEF
    • Dartmouth Card BASIC October 1964 DEF

    No equivalent in: Casio FX-700P BASIC, Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    NESTED_DEF A DEF inside a function of several lines. Form: Several lines. to verify
    UNFINISHED_DEF No FNEND. Form: Several lines. to verify
    ILLEGAL_FORMULA The formula is not written correctly. Parameter: formula. Form: One line. automatic to verify
    UNDEFINED_FUNCTION The formula uses an FN function that is never defined. Parameter: formula. Form: One line. automatic to verify
    MISMATCHED_STRING A string where a number is wanted. Parameter: formula. Form: One line. automatic to verify

    Notes

    Multi-line DEFs cannot be nested, and no jump may enter or leave them [4] p. 48. Whether a function can have more than one argument is to be checked in the manual.
