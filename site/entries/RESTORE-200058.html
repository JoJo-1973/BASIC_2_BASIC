    RESTORE Statement

    Starts the data list again: the next READ takes the first number.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition)
    In Dartmouth BASIC (4th edition)
    replaced by RESTORE of DARTMOUTH_4ED_layer

    Redefined in a later layer: RESTORE — RESTORE* and RESTORE$ restart only one of the two data lists.

    Syntax

    RESTORE

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 30): RESTORE

    Equivalents in other dialects

    DATA_RESTORE Restart the data list

    • Dartmouth BASIC (4th edition) RESTORE (Both lists); RESTORE (Numbers) partial — Only the numbers; RESTORE (Strings) partial — Only the strings

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM
