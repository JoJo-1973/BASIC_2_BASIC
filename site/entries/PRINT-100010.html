    Casio FX-700P BASIC ›

    PRINT Statement

    Shows numbers and strings on the display.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    ';' shows the next item after the previous one; ',' shows it after the display has been cleared. The program stops with STOP on the display until EXE is pressed.

    PRINT <CSR n | item> [<; | ,> <CSR n | item>]... [; | ,]

    In the manual (FX-700P Instruction Manual, p. 52): PRINT output control function {;|,} output element [{;|,} ...] differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M numeric expression
    truncated to integer    		 [0, 11]M
    		 Position of the next item, 0 to 11, decimal part cut off.
    item M numeric expression
    or character expression    		 Numeric or character expression. A number is shown with a sign position, so PRINT "N=";N shows N= 15.
