    IF Statement

    Executes the statement after THEN if the condition is not zero.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    IF condition THEN statement

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): IF n THEN statement differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    condition M condition How a value used as a condition is read: NONZERO
    		 False if 0, true otherwise. Comparisons give -1 or 0.
    statement M statement Any statement, with its keyword.
