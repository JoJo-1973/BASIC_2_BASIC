    CHR$ Function

    Character with the given code.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    CHR$(n)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): CHR$(n)

    Returns: String ($)

    ParameterTypeAllowed valuesDescription
    n ✓ numeric expression Character code, taken modulo 256: CHR$(256+38) is CHR$(38). CHR$(1) gives the empty string; CHR$(212) gives the quote.

    Equivalents in other dialects

    STR_CHR Character from its code — The ZX80's own character set, not ASCII
