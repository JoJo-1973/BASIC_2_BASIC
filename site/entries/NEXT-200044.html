    NEXT Statement

    Ends the loop of the FOR with the same variable.

    Layer
    DARTMOUTH_2ED_layer — Dartmouth BASIC, 2nd edition
    Dialects
    Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Redefines NEXT of the previous layer.
    Differences: Any unsubscripted variable.

    Syntax

    NEXT v

    In the manual (BASIC (1 October 1964), p. 29, 56): NEXT <unsubscripted variable> differs from the rebuilt syntax
