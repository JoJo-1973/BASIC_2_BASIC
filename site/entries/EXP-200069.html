    EXP Function

    e raised to the argument.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)

    Redefines EXP of the previous layer.
    Differences: A result too large gives a message.

    Syntax

    EXP(x)

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 25): EXP(A) differs from the rebuilt syntax

    Returns: Number, range [0, ∞) M

    ParameterTypeAllowed valuesDescription
    x M formula Any formula.
