    DATA Statement

    Numbers for READ, taken in the order of the DATA statements.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines DATA of the previous layer.
    Differences: Strings too.

    Syntax

    DATA item[,item]...

    In the manual (BASIC, 4th Edition (January 1968), p. 33-34): DATA differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    item M number
    or string    		 Numbers (not formulas) and strings, separated by commas.
