    LIST Direct command

    Types the current version of the program.

    Layer
    DARTMOUTH_2ED_layer — Dartmouth BASIC, 2nd edition
    Dialects
    Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)
    In Dartmouth Card BASIC October 1964
    removed by a higher layer

    Redefines LIST of the previous layer.
    Differences: Can start from a given line (LIST-n).

    Redefined in a later layer: LIST — Inferred: Card BASIC is run from a deck of cards, and the manual does not describe Teletype commands for it.

    Syntax

    LIST [-n]

    In the manual (BASIC (1 October 1964), p. 20): LIST - XXXXX differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M line number [1, 99999]M
    		 First line to list.
