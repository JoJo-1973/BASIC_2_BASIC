    DIM Statement

    Creates an array with subscripts from 0 to n.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    DIM a(n)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): DIM a(n)

    ParameterTypeAllowed valuesDescription
    a M numeric array name Array name: a single letter.
    n M numeric expression Highest subscript: the array has n+1 elements.

    Equivalents in other dialects

    VAR_DIM Declare an array partial— One dimension only, integers only

    • Dartmouth BASIC (1st edition) DIM partial — Numeric arrays of one or two dimensions
    • Dartmouth BASIC (2nd edition) DIM partial — Numeric arrays of one or two dimensions
    • Dartmouth BASIC (3rd edition) DIM partial — Numeric arrays of one or two dimensions
    • Dartmouth BASIC (4th edition) DIM partial — Numeric arrays of one or two dimensions

    No equivalent in: Casio FX-700P BASIC

    Tables

    • Variables in memory — action VAR_DIM

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameter: n. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE Negative size.
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameter: n. automatic to verify
    4 OUT_OF_MEMORY No room for the array. to verify
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameter: n. automatic to verify

    Notes
