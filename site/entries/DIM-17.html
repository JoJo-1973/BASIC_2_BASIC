    DIM Statement

    Creates an array with subscripts from 0 to n.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    DIM a(n)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): DIM a(n)

    ParameterTypeValuesDescription
    a numeric array name Array name: a single letter.
    n numeric expression Highest subscript: the array has n+1 elements.

    Equivalents in other dialects

    VAR_DIM Declare an array partial— One dimension only, integers only

    Keywords

    KeywordTokenAbbreviation
    DIM $E9
    ( $DA
    ) $D9

    Examples

    Notes

    If the array already exists, the new space is reserved but the old array is still used.

    Sources

    • Sinclair ZX80 Operating Manual - A Course in BASIC Programming, Hugo Davenport (1980), p. Appendix II
