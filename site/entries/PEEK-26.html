    PEEK Function

    Byte stored at the given address.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    PEEK(n)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): PEEK(n)

    Returns: Integer, range [0, 255] M

    ParameterTypeAllowed valuesDescription
    n M numeric expression Memory address.

    Equivalents in other dialects

    MEM_PEEK Read a byte from memory

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964
