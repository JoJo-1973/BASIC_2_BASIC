    NEXT Statement

    Increments the counter and goes back to the statement after FOR if it has not passed the end value.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    NEXT a

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): NEXT a

    ParameterTypeAllowed valuesDescription
    a M loop control variable name otherwise error 1 1/n Control variable of the loop.

    Notes

    Since the line to return to of a FOR loop is not kept on a stack, FOR loops that are not nested can be written without causing errors.

    • The body of a FOR loop is always executed at least once: Yes
    • The loop variable can be changed inside the loop: Yes
