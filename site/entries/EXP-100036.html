    EXP Function

    The number e (2.718281828...).

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    EXP 1

    In the manual (FX-700P Instruction Manual, p. 61): EXP 1

    Returns: Real number

    Examples

    Notes

    The manual calls it a command that calls out the value of the exponential table: the argument can only be 1. It cannot be used in a continuous calculation nor in a multistatement. For e↑x, assign EXP 1 to a variable and use ↑.
