    RUN Direct command

    Runs the program: same as CLEAR followed by GO TO n.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    RUN [n]

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): RUN n differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M numeric expression Range of line numbers: 1-9999
    missing line: the next existing line is used
    		 Starting line; without an argument it is 1.

    Equivalents in other dialects

    PROG_RUN Run the program — Also clears the variables

    • Casio FX-700P BASIC RUN
    • Dartmouth BASIC (1st edition) RUN
    • Dartmouth BASIC (2nd edition) RUN
    • Dartmouth BASIC (3rd edition) RUN
    • Dartmouth BASIC (4th edition) RUN

    No equivalent in: Dartmouth Card BASIC October 1964
