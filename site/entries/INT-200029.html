    INT Function

    Integer part, truncated towards zero.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964
    In Dartmouth BASIC (3rd edition)
    replaced by INT of DARTMOUTH_3ED_layer
    In Dartmouth BASIC (4th edition)
    replaced by INT of DARTMOUTH_3ED_layer

    Redefined in a later layer: INT — Floor instead of truncation: INT(-2.35) = -3.

    Syntax

    INT(x)

    In the manual (BASIC (1 October 1964), p. 39): INT(X)

    Returns: Number

    Notes

    The May manual only names it: taken from the 2nd edition manual [2] p. 39, where INT(-7.8) = -7. Rounding: INT(X+.5) for positive X, INT(X-.5) for negative X. Kurtz [9] quotes the complete 1st edition manual (June 1964, p. 31): INT(3.45) = 3, INT(-34.567) = -34.
