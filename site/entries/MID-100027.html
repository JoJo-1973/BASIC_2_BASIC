    MID Function

    Part of the exclusive character variable $.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    MID(m [,n])

    In the manual (FX-700P Instruction Manual, p. 55): MID (m [, n])

    Returns: Character string ($)

    ParameterTypeAllowed valuesDescription
    m M numeric expression
    truncated to integer    		 [1, 30]M
    		 First character, 1 to 30, decimal part cut off.
    n M numeric expression
    truncated to integer    		 [1, 30]M
    		 Number of characters, decimal part cut off; without it, all the characters from m on.

    Equivalents in other dialects

    STR_SUBSTRING Part of a string partial— Only on the exclusive variable $

    • Sinclair ZX80 BASIC 4K ROM TL$ partial — Only removes the first character

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Errors

    ErrorWhen
    3 MATHEMATICAL A calculation in the expression goes out of range, or its result is indefinite or impossible. Parameters: m, n. automatic to verify
    5 ARGUMENT m or n outside 1-30, or m+n greater than the number of characters plus 1 (inferred). to verify
    6 VARIABLE The expression uses a memory that has not been expanded, or a numeric and a character variable of the same letter. Parameters: m, n. automatic to verify

    Keywords

    KeywordTokenAbbreviation

    Examples

    Notes

    With $="ABCDEFGHIJ": MID(3,4) = CDEF, MID(1,2) = AB, MID(5) = EFGHIJ.
