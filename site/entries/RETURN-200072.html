    RETURN Statement

    Goes back to the statement after the last GOSUB.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)

    Redefines RETURN of the previous layer.
    Differences: The error is now RETURN BEFORE GOSUB, at run time.
