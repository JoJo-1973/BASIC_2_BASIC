    SQR Function

    Square root of the absolute value of the argument.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)

    Redefines SQR of the previous layer.
    Differences: A negative argument gives a message.

    Syntax

    SQR(x)

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 25): SQR(A) differs from the rebuilt syntax

    Returns: Number, range [0, ∞) M

    ParameterTypeAllowed valuesDescription
    x M formula Any formula.
