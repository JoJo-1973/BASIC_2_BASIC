    HELLO Direct command

    Starts a session: the system asks for the user number, the problem name, the system and whether the program is new or old.

    Notes

    The dialogue of [1] p. 17 (the user's answers after the dashes):

    USER NO.--446425 PROBLEM NO.--M36-2 SYSTEM--BASIC TYPE OR OLD--TYPE READY.

    The problem name has up to 6 letters, digits or symbols. TYPE starts a new program, OLD brings back a saved one. HELLO is typed only to start a new problem, not to correct a program.
