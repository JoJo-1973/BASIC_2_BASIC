    FOR...TO...STEP Statement

    Starts a loop: the variable goes from the start value to the end value in steps of the given increment.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    FOR v = e1 TO e2 [STEP e3]

    In the manual (FX-700P Instruction Manual, p. 45): FOR v=e1 TO e2 [STEP e3]

    ParameterTypeAllowed valuesDescription
    v M numeric variable Numeric variable.
    e1 M numeric expression Start value.
    e2 M numeric expression End value.
    e3 M numeric expression Increment; 1 if STEP is omitted. To count down it must be negative (STEP -1).

    Notes

    The loop is repeated [(e2-e1)/e3]+1 times. Up to 4 nested loops; a loop can be left with a jump but not entered. Numbers are decimal inside, so steps like 0.01 add up exactly.

    • The body of a FOR loop is always executed at least once: Yes to verify
    • The loop variable can be changed inside the loop: Yes to verify
