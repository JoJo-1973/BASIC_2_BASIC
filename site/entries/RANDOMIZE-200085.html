    RANDOMIZE Statement

    Starts RND from an unpredictable point.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Syntax

    RANDOMIZE

    In the manual (BASIC, 4th Edition (January 1968), p. 45): RANDOMIZE

    Equivalents in other dialects

    RND_SEED Seed the random numbers partial— No seed value: an unpredictable start

    • Sinclair ZX80 BASIC 4K ROM RANDOMISE

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964
