    INPUT Statement

    Types a question mark and waits for values typed at the Teletype.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines INPUT of the previous layer.
    Differences: Strings, and messages for wrong input.

    Syntax

    INPUT variable[,variable]...

    In the manual (BASIC, 4th Edition (January 1968), p. 50-51): INPUT X, Y differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    variable M variable or element Variables or elements, separated by commas; the values are typed the same way.

    Equivalents in other dialects

    IO_INPUT Read values from the keyboard

    • Casio FX-700P BASIC INPUT
    • Dartmouth BASIC (3rd edition) INPUT
    • Sinclair ZX80 BASIC 4K ROM INPUT partial — One variable only, no prompt

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964

    Notes

    Types ?; the values are separated by commas. A PRINT ending with ';' keeps the question mark on its line. Strings can be typed without quotes if they start with a letter [4] pp. 50-51, 64.
