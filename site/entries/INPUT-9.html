    INPUT Statement

    Reads a value from the keyboard and assigns it to a variable.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    INPUT destination

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): INPUT dest differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    destination M numeric variable name
    or string variable name
    or numeric array element    		 Numeric variable, string variable or array element. An expression can be typed.

    Equivalents in other dialects

    IO_INPUT Read values from the keyboard partial— One variable only, no prompt

    Tables

    • Variables in memory — action IO_INPUT

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND The array has not been dimensioned. Parameter: destination. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE Subscript out of range, or an error while computing it. Parameter: destination. automatic to verify
    4 OUT_OF_MEMORY No room for a new variable or for a longer string. to verify
    8 INPUT_AS_COMMAND Used as a command, outside a program.

    Keywords

    KeywordTokenAbbreviation
    INPUT $EE I

    Examples

    Notes

    Only inside a program: as a command it gives error 8. For a string the quotes appear, and they can be deleted.
