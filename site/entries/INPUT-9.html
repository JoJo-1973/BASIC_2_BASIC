    INPUT Statement

    Reads a value from the keyboard and assigns it to a variable.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    INPUT destination

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): INPUT dest differs from the rebuilt syntax

    ParameterTypeValuesDescription
    destination numeric variable name
    or string variable name
    or numeric array element    		 otherwise ?INPUT AS COMMAND Numeric variable, string variable or array element. An expression can be typed.

    Equivalents in other dialects

    IO_INPUT Read values from the keyboard partial— One variable only, no prompt

    Keywords

    KeywordTokenAbbreviation
    INPUT $EE

    Notes

    Only inside a program: as a command it gives error 8. For a string the quotes appear, and they can be deleted.
