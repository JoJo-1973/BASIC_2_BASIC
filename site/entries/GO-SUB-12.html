    GO SUB Statement

    Calls the subroutine that starts at the given line; RETURN goes back to the next line.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    GO SUB n

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): GO SUB n

    ParameterTypeAllowed valuesDescription
    n M numeric expression Range of line numbers: 1-9999
    missing line: the next existing line is used
    		 Line number (also an expression). Beyond the end of the program execution stops with 0/n.

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameter: n. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameter: n. automatic to verify
    4 OUT_OF_MEMORY No room for the return address. to verify
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameter: n. automatic to verify
