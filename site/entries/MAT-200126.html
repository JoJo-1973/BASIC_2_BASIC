    MAT Statement

    Matrix arithmetic: sum, difference, product, multiple, zero, ones, identity, transpose, inverse.

    Layer
    DARTMOUTH_CARD_layer — Card BASIC
    Dialects
    Dartmouth Card BASIC October 1964

    Sum

    MAT c = a + b

    In the manual (BASIC (1 October 1964), p. 51-52): MAT C = A + B

    ParameterTypeAllowed valuesDescription
    c matrix name
    a matrix name
    b matrix name

    Equivalents in other dialects

    MAT_ADD Matrix addition

    • Dartmouth BASIC (3rd edition) MAT (Sum)
    • Dartmouth BASIC (4th edition) MAT (Sum)

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Sinclair ZX80 BASIC 4K ROM

    ILLEGAL_FORMULA The formula is not written correctly. Parameters: k, m, n. Form: Multiple, Zero matrix, Ones, Identity. automatic to verify
    UNDEFINED_FUNCTION The formula uses an FN function that is never defined. Parameters: k, m, n. Form: Multiple, Zero matrix, Ones, Identity. automatic to verify
