    GOSUB Statement

    Calls a subroutine: RETURN goes back to the statement after the GOSUB.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964
    In Dartmouth BASIC (3rd edition)
    replaced by GOSUB of DARTMOUTH_3ED_layer
    In Dartmouth BASIC (4th edition)
    replaced by GOSUB of DARTMOUTH_3ED_layer

    Redefined in a later layer: GOSUB — Subroutines can call other subroutines.

    Syntax

    GOSUB n

    In the manual (BASIC (1 October 1964), p. 42-43): GOSUB N

    ParameterTypeAllowed valuesDescription

    Range of line numbers: 1-99999 (Dartmouth Card BASIC October 1964) to verify
    missing line: error
    otherwise error UNDEFINED NUMBER (Dartmouth BASIC (1st edition))

    otherwise error UNDEFINED NUMBER (Dartmouth Card BASIC October 1964)    		 Line number: an integer of up to five digits, written as a number (not a formula).

    Notes

    Part II of the May manual is missing: taken from the 2nd edition manual [2] pp. 42-43, which says that a GOSUB inside a subroutine "just won't work": no nesting. The compiler of February 1965 (DTSS-Win) already runs nested GOSUBs correctly. Kurtz [9] writes that GOSUB "used a stack for the return address", which does not agree with [2].
