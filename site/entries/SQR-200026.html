    SQR Function

    Square root of the absolute value of the argument.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth Card BASIC October 1964
    In Dartmouth BASIC (3rd edition)
    replaced by SQR of DARTMOUTH_3ED_layer
    In Dartmouth BASIC (4th edition)

    Redefined in a later layer: SQR — A negative argument gives a message.

    Syntax

    SQR(x)

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 5): SQR(A) differs from the rebuilt syntax

    Returns: Number, range [0, ∞) M

    Notes

    The square root is always taken of the absolute value: SQR(-4) = 2, with no message [1] p. 5. The compiler of February 1965 (DTSS-Win) prints SQUARE ROOT OF NEGATIVE NUMBER IN n, then goes on with the root of the absolute value.
