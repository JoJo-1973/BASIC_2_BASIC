    Sinclair ZX80 BASIC 4K ROM ›

    NEW Direct command

    Returns the computer to its power-on state: erases program and variables.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    NEW

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): NEW

    Equivalents in other dialects

    PROG_NEW Erase the program

    • Casio FX-700P BASIC CLEAR (Current area) partial — Only the current program area; CLEAR (All areas)
    • Dartmouth BASIC (2nd edition) NEW; SCRATCH partial — Keeps the name
    • Dartmouth BASIC (3rd edition) NEW; SCRATCH partial — Keeps the name
    • Dartmouth BASIC (4th edition) NEW; SCRATCH partial — Keeps the name

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth Card BASIC October 1964
