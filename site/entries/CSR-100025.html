    Casio FX-700P BASIC ›

    CSR Function

    Inside PRINT: shows the next item from the given position of the display.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    CSR n

    In the manual (FX-700P Instruction Manual, p. 53): CSR n {;|,} differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M numeric expression
    truncated to integer    		 [0, 11]M
    		 Position 0 to 11, decimal part cut off.

    Equivalents in other dialects

    IO_POSITION Output from a given position

    • Dartmouth BASIC (4th edition) PRINT — TAB(n); TAB

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    3 MATHEMATICAL A calculation in the expression goes out of range, or its result is indefinite or impossible. Parameter: n. automatic to verify
    5 ARGUMENT Position outside 0-11 (inferred). to verify
    6 VARIABLE The expression uses a memory that has not been expanded, or a numeric and a character variable of the same letter. Parameter: n. automatic to verify

    Keywords

    KeywordTokenAbbreviation
    CSR $94 F + M (Casio FX-700P), none (Casio PB-100), none (Tandy Radio Shack TRS-80 PC-4)

    Examples

    Notes

    After CSR n, ';' shows the next item from position n; ',' shows nothing until the display is cleared.
