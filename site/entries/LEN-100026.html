    LEN Function

    Number of characters of a character variable.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    LEN(v)

    In the manual (FX-700P Instruction Manual, p. 55): LEN (character variable) differs from the rebuilt syntax

    Returns: Real number, range [0, 30] M

    ParameterTypeAllowed valuesDescription
    v M character variable Only a character variable.

    Equivalents in other dialects

    STR_LEN Length of a string

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM
