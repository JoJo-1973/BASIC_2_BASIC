    PRINT Statement

    Writes on the upper part of the screen.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    ';' joins the items; ',' moves to the next zone (columns 9, 17, 25). A trailing separator suppresses the new line.

    PRINT [item][<; | ,>[item]]...

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): PRINT list differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    item M numeric expression
    or string expression    		 Numeric or string expression. Strings appear without quotes, numbers as with STR$.

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameter: item. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameter: item. automatic to verify
    5 SCREEN_FULL No more room on the upper part of the screen.
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameter: item. automatic to verify
