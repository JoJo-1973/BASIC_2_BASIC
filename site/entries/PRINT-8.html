    PRINT Statement

    Writes on the upper part of the screen.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    ';' joins the items; ',' moves to the next zone (columns 9, 17, 25). A trailing separator suppresses the new line.

    PRINT [item][<; | ,>[item]]...

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): PRINT list differs from the rebuilt syntax

    ParameterTypeValuesDescription
    item numeric expression
    or string expression    		 Numeric or string expression. Strings appear without quotes, numbers as with STR$.

    Equivalents in other dialects

    IO_PRINT Write to the screen
