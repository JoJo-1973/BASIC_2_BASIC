    TL$ Function

    The string without its first character.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    TL$(s)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): TL$(s)

    Returns: String ($)

    ParameterTypeAllowed valuesDescription
    s string expression

    Equivalents in other dialects

    STR_SUBSTRING Part of a string partial— Only removes the first character

    • Casio FX-700P BASIC MID partial — Only on the exclusive variable $

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameter: s. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameter: s. automatic to verify
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameter: s. automatic to verify

    Keywords

    KeywordTokenAbbreviation

    Examples

    Notes

    TL$("") gives the empty string, without any error.
