    READ Statement

    Gives the variables the next numbers of the DATA statements.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Redefines READ of the previous layer.
    Differences: Strings; the data are two separate lists.

    Syntax

    READ variable[,variable]...

    In the manual (BASIC, 4th Edition (January 1968), p. 33, 66): READ A, B, C differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    variable M variable or element Variables or elements, separated by commas.

    Equivalents in other dialects

    DATA_READ Read values from the data list

    • Dartmouth BASIC (1st edition) READ
    • Dartmouth BASIC (2nd edition) READ
    • Dartmouth BASIC (3rd edition) READ
    • Dartmouth Card BASIC October 1964 READ

    No equivalent in: Casio FX-700P BASIC, Sinclair ZX80 BASIC 4K ROM

    Tables

    • Variables in memory — action DATA_READ

    Errors

    ErrorWhen
    OUT_OF_DATA No data left. to verify
    NO_NUMERIC_DATA A number is read but DATA holds none. to verify
    NO_STRING_DATA A string is read but DATA holds none. to verify

    KeywordTokenAbbreviation
    READ

    Examples

    Notes

    Numbers and strings of the DATA statements form two separate lists: a numeric READ takes the next number, a string READ the next string [4] p. 66. When the data run out: OUT OF DATA [4] p. 33.
