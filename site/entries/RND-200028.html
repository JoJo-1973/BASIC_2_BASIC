    RND Function

    Random number between 0 and 1.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964
    In Dartmouth BASIC (4th edition)
    replaced by RND of DARTMOUTH_4ED_layer

    Redefined in a later layer: RND — No argument.

    Syntax

    RND(x)

    In the manual (BASIC (1 October 1964), p. 39-40): RND(X)

    Returns: Number, range [0, 1] M

    ParameterTypeAllowed valuesDescription
    x M formula Has no significance, but must be written.

    Notes

    The May manual only names it ("see Part II"): taken from the 2nd edition manual [2] pp. 39-40. Every run gives the same sequence. DTSS-Win (compiler of February 1965) confirms it: in LIB/GUESS, INT(100*RND(0)+1) gives 75 at the start of every RUN, then 20. Kurtz [9] confirms the dummy argument in the 1st edition ("no doubt we were merely being lazy").
