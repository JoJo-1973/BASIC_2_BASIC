    SAVE Direct command

    Keeps the program on the disk, under its problem name.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)
    In Dartmouth Card BASIC October 1964
    removed by a higher layer

    Redefined in a later layer: SAVE — Inferred: Card BASIC is run from a deck of cards, and the manual does not describe Teletype commands for it.

    Syntax

    SAVE

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 18): SAVE

    Equivalents in other dialects
