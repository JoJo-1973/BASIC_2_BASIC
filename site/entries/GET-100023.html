    Casio FX-700P BASIC ›

    GET Statement

    Loads variables from tape.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    GET [filename] first [, last]

    In the manual (FX-700P Instruction Manual, p. 64): GET ["filename"] variable differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    filename M string literal Up to 8 letters, digits or symbols, in quotes. Without it, the first file found.
    first M any variable First variable.
    last M any variable Last variable.

    Equivalents in other dialects

    TAPE_LOAD_DATA Load variables

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    9 OPTION No tape recorder connected. automatic to verify
