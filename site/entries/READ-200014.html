    READ Statement

    Gives the variables the next numbers of the DATA statements.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition)
    In Dartmouth BASIC (3rd edition)
    replaced by READ of DARTMOUTH_3ED_layer
    In Dartmouth BASIC (4th edition)
    replaced by READ of DARTMOUTH_4ED_layer
    In Dartmouth Card BASIC October 1964
    replaced by READ of DARTMOUTH_CARD_layer

    Redefined in a later layer: READ — Running out of data prints OUT OF DATA.

    Redefined in a later layer: READ — The numbers come from the data deck after the END card, with no limit.

    Syntax

    READ variable[,variable]...

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 14-15): READ A, B, C differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    variable M variable or element Variables or elements, separated by commas.

    Equivalents in other dialects

    DATA_READ Read values from the data list

    • Dartmouth BASIC (3rd edition) READ
    • Dartmouth BASIC (4th edition) READ
    • Dartmouth Card BASIC October 1964 READ

    No equivalent in: Casio FX-700P BASIC, Sinclair ZX80 BASIC 4K ROM

    Notes

    When there is no data left, the program stops, with no message [1] p. 15. The compiler of February 1965 (DTSS-Win) already prints OUT OF DATA IN n and stops.
