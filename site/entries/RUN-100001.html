    Casio FX-700P BASIC ›

    RUN Direct command

    Runs the program of the current area.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    RUN [n]

    In the manual (FX-700P Instruction Manual, p. 27): RUN [line number] differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M numeric literal Line to start from; without it, the first line.

    Equivalents in other dialects

    PROG_RUN Run the program

    • Dartmouth BASIC (1st edition) RUN
    • Dartmouth BASIC (2nd edition) RUN
    • Dartmouth BASIC (3rd edition) RUN
    • Dartmouth BASIC (4th edition) RUN
    • Sinclair ZX80 BASIC 4K ROM RUN — Also clears the variables

    No equivalent in: Dartmouth Card BASIC October 1964

    Tables

    • Program in memory — action PROG_RUN

    Keywords

    KeywordTokenAbbreviation

    Notes

    A program can also be started with S and the number of its area (S 0 to S 9) in RUN mode.

    In a program: not known on the real machine. The PokecomGO2 simulator (source [9]) gives error 2 for 10 RUN 20, probably because it skips RUN and then reads the 20 as a syntax error.
