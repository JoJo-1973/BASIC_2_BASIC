    Casio FX-700P BASIC ›

    MODE Statement

    Chooses the angle unit, or switches the printer on and off.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Angle unit

    MODE n

    In the manual (FX-700P Instruction Manual, p. 47): MODE {4|5|6} differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M numeric literal 4M = degrees
    5M = radians
    6M = gradians
    		 Angle unit.

    Equivalents in other dialects

    MATH_ANGLE_UNIT Choose the angle unit

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Printer

    MODE n
    ParameterTypeAllowed valuesDescription
    n M numeric literal 7M = printing on (PRT)
    8M = printing off
    		 Printer.

    Equivalents in other dialects

    IO_PRINTER Send the output to the printer

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Notes

    With the MODE key, MODE 0 (RUN), 1 (WRT), 2 and 3 (trace on and off) and MODE . (extension, small letters and symbols) are key operations. After MODE 7, write MODE 8 before the end of the program.
