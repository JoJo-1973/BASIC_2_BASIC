    GOSUB Statement

    Calls a subroutine: RETURN goes back to the statement after the GOSUB.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)

    Redefines GOSUB of the previous layer.
    Differences: Subroutines can call other subroutines.

    Syntax

    GOSUB n

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 28): GOSUB N

    ParameterTypeAllowed valuesDescription
    n M line number [1, 99999]M
    Range of line numbers: 1-99999 (Dartmouth BASIC (3rd edition)) to verify
    Range of line numbers: 1-99999 (Dartmouth BASIC (4th edition)) to verify
    missing line: error
    otherwise error UNDEFINED NUMBER (Dartmouth BASIC (3rd edition))
    otherwise error UNDEFINED LINE NUMBER (Dartmouth BASIC (4th edition))    		 Line number: an integer of up to five digits, written as a number (not a formula).

    Notes

    GOSUB can be nested; the depth limit is not given (GOSUB NESTED TOO DEEPLY). A subroutine should be left only with RETURN [3] p. 28.
