    Casio FX-700P BASIC ›

    SAVE Direct command

    Records on tape the program of the current area, or (SAVE A) the programs of all areas.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Current area

    SAVE [filename]

    In the manual (FX-700P Instruction Manual, p. 63): SAVE ["filename"] differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    filename M string literal Up to 8 letters, digits or symbols, in quotes. Without it, the first file found.

    Notes

    The A of the "all areas" form is the letter A, not a keyword: it has no token of its own (the token tables of source [5] have only LIST, CLEAR, SAVE and LOAD).

    Only manually. On tape a program file is a header ($D0 plus the length of the name, 8 characters of name, number of the first line) and the program lines in segments of up to 63 bytes, each started by $02 and ended by $F1; the last ends with $F0. Each byte is sent with a start bit, an even parity bit and stop bits (source [5]).

    SAVE A: on tape the file starts with $F0 plus the length of the name; the ten programs follow in one segment, each ended by $E0 (an empty program is $E0 alone) (source [7]).
