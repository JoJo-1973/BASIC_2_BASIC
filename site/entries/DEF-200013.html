    DEF Statement

    Defines a function FNA to FNZ with one argument.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964
    In Dartmouth BASIC (4th edition)
    replaced by DEF of DARTMOUTH_4ED_layer

    Redefined in a later layer: DEF — Functions without argument, and functions of several lines ended by FNEND.

    Syntax

    DEF FNletter(argument) = formula

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 13): DEF FNC(Z) = Z↑3 + 2.7*Z differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    letter M function letter A to Z: up to 26 functions.
    argument M variable Used only for the definition; the manual says not to use it elsewhere in the program.
    formula M formula Any formula containing the argument; on one line.

    Equivalents in other dialects

    FN_DEFINE Define a function

    • Dartmouth BASIC (4th edition) DEF (One line); DEF (Several lines) — Several lines, ended by FNEND

    No equivalent in: Casio FX-700P BASIC, Sinclair ZX80 BASIC 4K ROM

    Notes

    DEF may be anywhere in the program. DEF FNS(Z) = SIN(Z*P/180) gives a sine in degrees, DEF FNL(Z) = LOG(Z)/LOG(10) a common logarithm [1] p. 13.
