    FN Function

    Calls a function defined with DEF.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Syntax

    FNletter(x)

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 13): FNC(X) differs from the rebuilt syntax

    Returns: Number

    ParameterTypeAllowed valuesDescription
    letter M function letter Letter of a function defined with DEF.
    x M formula Any formula.

    Equivalents in other dialects

    FN_CALL Call a user function

    No equivalent in: Casio FX-700P BASIC, Sinclair ZX80 BASIC 4K ROM
