    GO TO Statement

    Jumps to a line.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Syntax

    GO TO n

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 11): GO TO N

    ParameterTypeAllowed valuesDescription
    n M line number [1, 99999]M
    Range of line numbers: 1-99999 (Dartmouth BASIC (1st edition)) to verify
    Range of line numbers: 1-99999 (Dartmouth BASIC (2nd edition)) to verify
    Range of line numbers: 1-99999 (Dartmouth BASIC (3rd edition)) to verify
    Range of line numbers: 1-99999 (Dartmouth BASIC (4th edition)) to verify
    Range of line numbers: 1-99999 (Dartmouth Card BASIC October 1964) to verify
    missing line: error
    otherwise error UNDEFINED NUMBER (Dartmouth BASIC (1st edition))
    otherwise error UNDEFINED NUMBER (Dartmouth BASIC (2nd edition))
    otherwise error UNDEFINED NUMBER (Dartmouth BASIC (3rd edition))
    otherwise error UNDEFINED LINE NUMBER (Dartmouth BASIC (4th edition))
    otherwise error UNDEFINED NUMBER (Dartmouth Card BASIC October 1964)    		 Line number: an integer of up to five digits, written as a number (not a formula).
