    LOG Function

    Natural logarithm.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition)

    Redefines LOG of the previous layer.
    Differences: A negative or zero argument gives a message.

    Syntax

    LOG(x)

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 25): LOG(A) differs from the rebuilt syntax

    Returns: Number

    ParameterTypeAllowed valuesDescription
    x M formula Any formula.

    Notes
