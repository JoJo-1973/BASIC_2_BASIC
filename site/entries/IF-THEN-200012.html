    IF...THEN Statement

    Jumps to a line if a relation between two formulas is true.

    Layer
    DARTMOUTH_1ED_core — Dartmouth BASIC, 1st edition
    Dialects
    Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964
    In Dartmouth BASIC (4th edition)
    replaced by IF...THEN of DARTMOUTH_4ED_layer

    Redefined in a later layer: IF...THEN — Strings can be compared; GO TO can replace THEN.

    Syntax

    IF relation THEN n

    In the manual (BASIC Instruction Manual, May 1964 (First Draft), p. 11-12): IF F1 α F2 THEN N differs from the rebuilt syntax

    Notes

    If the relation is false the program goes on with the next statement. GO TO and IF...THEN may jump to a REM or DATA line, which does nothing [2] p. 45.
