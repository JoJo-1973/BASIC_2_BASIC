    MAT READ Statement

    Reads one matrix of the dimensions shown from the data.

    Layer
    DARTMOUTH_CARD_layer — Card BASIC
    Dialects
    Dartmouth Card BASIC October 1964

    Syntax

    MAT READ matrix(m[,n])

    In the manual (BASIC (1 October 1964), p. 51-52): MAT READ A(M,N) differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    matrix M matrix name A matrix with a DIM.
    m M formula Rows: a formula, at most the DIM.
    n M formula Columns; without it a column vector.

    Equivalents in other dialects

    MAT_READ Read a matrix from the data list

    • Dartmouth BASIC (3rd edition) MAT READ
    • Dartmouth BASIC (4th edition) MAT READ

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    DIMENSION_TOO_LARGE More than the limits of [2] p. 51. to verify
    ILLEGAL_FORMULA The formula is not written correctly. Parameters: m, n. automatic to verify
    UNDEFINED_FUNCTION The formula uses an FN function that is never defined. Parameters: m, n. automatic to verify

    Examples

    Notes

    The dimensions can be formulas: DIM A(20,20), READ M, MAT READ A(M,M) reads a square matrix of any size up to 20 × 20 [2] p. 52. A matrix must be first used in a MAT statement.
