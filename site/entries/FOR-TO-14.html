    FOR...TO Statement

    Starts a loop: the counter goes from the start value to the end value in steps of 1.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    FOR a = start TO end

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): FOR a = n TO n differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    a loop control variable name Control variable: a single letter.
    start numeric expression Start value.
    end numeric expression End value.

    Equivalents in other dialects

    FLOW_FOR Start of a counted loop partial— Step fixed at 1: there is no STEP

    Notes

    At the end of the loop the counter is end+1. NEXT is matched dynamically. Since the line to return to is not kept on a stack, FOR loops that are not nested can be written without causing errors.

    • The body of a FOR loop is always executed at least once: Yes
    • The loop variable can be changed inside the loop: Yes
