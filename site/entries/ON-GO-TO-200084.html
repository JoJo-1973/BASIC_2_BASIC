    ON...GO TO Statement

    Jumps to the first, second, ... line of the list, according to the value of a formula.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    Syntax

    ON f <GO TO | THEN> lines

    In the manual (BASIC, 4th Edition (January 1968), p. 36): ON expr GO TO l1, l2, ... differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    f M formula
    truncated to integer    		 Integer part 1 selects the first line, 2 the second, ...
    lines M line numbers Range of line numbers: 1-99999 to verify
    missing line: error
    otherwise error UNDEFINED LINE NUMBER    		 Line numbers separated by commas.

    Equivalents in other dialects

    FLOW_ON_GOTO Computed jump

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    ON_OUT_OF_RANGE The integer part is below 1 or beyond the number of lines. to verify
    UNDEFINED_NUMBER A jump to a line that does not exist: UNDEFINED LINE NUMBER 50 IN 20 [4] p. 31. Parameter: lines. automatic to verify
    ILLEGAL_FORMULA The formula is not written correctly. Parameter: f. automatic to verify
    UNDEFINED_FUNCTION The formula uses an FN function that is never defined. Parameter: f. automatic to verify
    MISMATCHED_STRING A string where a number is wanted. Parameter: f. automatic to verify

    Notes
