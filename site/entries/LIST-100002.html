    Casio FX-700P BASIC ›

    LIST Direct command

    Lists the program of the current area, or (LIST A) the programs of all areas and the data in all memories.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Current area

    LIST [n]

    In the manual (FX-700P Instruction Manual, p. 28): LIST [line number] differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M numeric literal Line to start from; without it, the first line.

    Equivalents in other dialects

    Notes

    The A of the "all areas" form is the letter A, not a keyword: it has no token of its own (the token tables of source [5] have only LIST, CLEAR, SAVE and LOAD).

    In a program: not known on the real machine (the manual says the tape commands work only manually). The PokecomGO2 simulator (source [9]) accepts the line and skips the command when it is reached, with no error. Tried with 10 LIST.
