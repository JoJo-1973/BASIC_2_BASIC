    LIST Direct command

    Lists the program from a given line, which becomes the current line.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    LIST [n]

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): LIST n differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    n M numeric expression Range of line numbers: 1-9999
    missing line: the next existing line is used
    		 Line to start from; without an argument it is 0. An error while computing n is not reported.

    Equivalents in other dialects

    PROG_LIST List the program

    • Casio FX-700P BASIC LIST (Current area); LIST (All areas) — All areas, and the variables too

    • Dartmouth BASIC (4th edition) LIST

    No equivalent in: Dartmouth Card BASIC October 1964
