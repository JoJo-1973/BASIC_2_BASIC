    LET Statement

    Assigns a value to a variable.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    LET variable = expression
    ParameterTypeAllowed valuesDescription
    variable M numeric variable name
    or numeric array element
    or string variable name    		 Numeric variable, string variable or array element.
    expression M numeric expression
    or string expression    		 Of the same type as the variable.

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND The array has not been dimensioned. Parameter: variable. automatic to verify
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameter: expression. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE Subscript out of range, or an error while computing it. Parameter: variable. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameter: expression. automatic to verify
    4 OUT_OF_MEMORY No room for a new variable or for a longer string. to verify
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameter: expression. automatic to verify
