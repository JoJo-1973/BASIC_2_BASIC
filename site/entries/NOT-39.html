    NOT Operator

    Bitwise negation: NOT n is -n-1.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    NOT a

    Class: bitwise operators · Precedence: 4 (precedence table)

    Returns: Integer

    ParameterTypeAllowed valuesDescription

    Notes

    Each bit of the result:

    a NOT a
    0 1
    1 0

    With truth values (comparisons give -1 if true, 0 if false) it also behaves as a conditional operator: this is a side effect of working bit by bit on signed 16-bit integers, the only numeric type.

    • Value produced by a true comparison: -1
    • Value produced by a false comparison: 0
    • How a value used as a condition is read: NONZERO
