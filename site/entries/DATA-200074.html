    DATA Statement

    Numbers for READ, taken in the order of the DATA statements.

    Layer
    DARTMOUTH_3ED_layer — Dartmouth BASIC, 3rd edition
    Dialects
    Dartmouth BASIC (3rd edition)
    In Dartmouth BASIC (4th edition)
    replaced by DATA of DARTMOUTH_4ED_layer

    Redefines DATA of the previous layer.
    Differences: Up to 1280 numbers.

    Redefined in a later layer: DATA — Strings too.

    Syntax

    DATA number[,number]...

    In the manual (BASIC Language Reference Manual (June 1965, rev. January 1967), p. 20): DATA 1, 2, 3 differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    number M number Numbers separated by commas, as many as fit on the line.
