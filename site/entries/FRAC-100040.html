    FRAC Function

    The argument without its integer part.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    FRAC x

    In the manual (FX-700P Instruction Manual, p. 61): FRAC x

    Returns: Real number

    ParameterTypeAllowed valuesDescription
    x M numeric expression Constant, variable or numeric expression. Without parentheses only the number or variable that follows is the argument, since functions come first: SIN A+B is (SIN A)+B.

    Equivalents in other dialects

    MATH_FRAC Fractional part

    No equivalent in: Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Errors

    ErrorWhen
    3 MATHEMATICAL A calculation in the expression goes out of range, or its result is indefinite or impossible. Parameter: x. automatic to verify
    6 VARIABLE The expression uses a memory that has not been expanded, or a numeric and a character variable of the same letter. Parameter: x. automatic to verify
