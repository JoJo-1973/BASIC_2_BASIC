    USR Function

    Calls a machine code routine and returns its value.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    USR(n)

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): USR(n)

    Returns: Integer

    ParameterTypeAllowed valuesDescription
    n M numeric expression Address of the routine.

    Equivalents in other dialects

    MEM_CALL Call a machine code routine — Returns HL, or n if HL does not change

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth BASIC (4th edition), Dartmouth Card BASIC October 1964

    Errors

    ErrorWhen
    2 VARIABLE_NOT_FOUND A variable in the expression is not defined. Parameter: n. automatic to verify
    3 SUBSCRIPT_OUT_OF_RANGE An array element in the expression has a subscript out of range. Parameter: n. automatic to verify
    6 OVERFLOW A calculation in the expression goes outside the range from -32768 to 32767. Parameter: n. automatic to verify
