    Dartmouth BASIC (4th edition) ›

    CHANGE Statement

    Turns a string into a list of character codes, or a list of codes into a string.

    Layer
    DARTMOUTH_4ED_layer — Dartmouth BASIC, 4th edition
    Dialects
    Dartmouth BASIC (4th edition)

    String to codes

    CHANGE s TO v

    In the manual (BASIC, 4th Edition (January 1968), p. 67-69): CHANGE A$ TO A differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    s M string variable A string variable.
    v M list or table name A numeric list: element 0 gets the length, the others the codes.

    Equivalents in other dialects

    STR_TO_CODES String converted to character codes

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM

    Codes to string

    CHANGE v TO s

    In the manual (BASIC, 4th Edition (January 1968), p. 67-69): CHANGE A TO A$ differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    v M list or table name A numeric list: element 0 holds the number of characters.
    s M string variable A string variable.

    Equivalents in other dialects

    STR_FROM_CODES String built from character codes

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Dartmouth BASIC (3rd edition), Dartmouth Card BASIC October 1964, Sinclair ZX80 BASIC 4K ROM
