    RAN# Function

    Random number between 0 and 1.

    Layer
    FX700P_core — Casio FX-700P BASIC
    Dialects
    Casio FX-700P BASIC

    Syntax

    RAN#

    In the manual (FX-700P Instruction Manual, p. 61): RAN #

    Returns: Real number, range (0, 1) M

    Equivalents in other dialects

    RND_VALUE Random number partial— Only between 0 and 1

    • Dartmouth BASIC (3rd edition) RND partial — Only between 0 and 1
    • Dartmouth BASIC (4th edition) RND partial — Only between 0 and 1
    • Dartmouth Card BASIC October 1964 RND partial — Only between 0 and 1

    Keywords

    KeywordTokenAbbreviation
    RAN# $8F F + N (Casio FX-700P), none (Casio PB-100), none (Tandy Radio Shack TRS-80 PC-4)

    Examples

    Notes

    10 significant digits: RND(RAN#,-4)*1000 gives a three-digit number. The seed is kept in memory at $0110 and starts at 0.43429448190 (source [7]).
