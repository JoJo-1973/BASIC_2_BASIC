    CONTINUE Direct command

    Resumes execution from the line of the last n/m report; after STOP (9/m) from line m+1.

    Layer
    ZX80_4K_core — Sinclair ZX80 BASIC (4K ROM)
    Dialects
    Sinclair ZX80 BASIC 4K ROM

    Syntax

    CONTINUE

    In the manual (Sinclair ZX80 Operating Manual - A Course in BASIC Programming, p. Appendix II): CONTINUE

    Equivalents in other dialects
