    MAT PRINT Statement

    Prints one matrix; vectors are printed as rows.

    Layer
    DARTMOUTH_CARD_layer — Card BASIC
    Dialects
    Dartmouth Card BASIC October 1964

    Syntax

    Followed by the 5-8 punch (;) the matrix is printed packed.

    MAT PRINT matrix [;]

    In the manual (BASIC (1 October 1964), p. 51-52): MAT PRINT A differs from the rebuilt syntax

    ParameterTypeAllowed valuesDescription
    matrix M matrix name A matrix or vector.

    Equivalents in other dialects

    MAT_PRINT Print a matrix

    • Dartmouth BASIC (3rd edition) MAT PRINT
    • Dartmouth BASIC (4th edition) MAT PRINT

    No equivalent in: Casio FX-700P BASIC, Dartmouth BASIC (1st edition), Dartmouth BASIC (2nd edition), Sinclair ZX80 BASIC 4K ROM
